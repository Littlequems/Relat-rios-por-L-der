# Relatórios por Líder

Demonstração pública sanitizada desenvolvida para o portfólio da **CarolTech**.

## Visão geral
Fluxo de tratamento de listas que consolida registros, remove duplicidades, classifica situações e produz relatórios padronizados por responsável.

## Capacidades
- Importação de listas
- Deduplicação de registros
- Classificação de situação
- Resumo por responsável
- Geração de PDF
- Padronização visual

## Privacidade
Este repositório público **não contém nomes, CPFs, telefones ou dados reais**. Toda informação exibida é fictícia e exclusiva para demonstração.
